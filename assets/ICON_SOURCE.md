# Icon source

Icons are downloaded from the selfh.st icon collection (repository `selfhst/icons`, served via
jsdelivr). No icon was drawn from scratch.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/wazuh.svg` | Default (light backgrounds) |
| `icon-dark.svg` | `svg/wazuh.svg`, modified | Dark backgrounds (dark mode) |

Download URLs:

- https://cdn.jsdelivr.net/gh/selfhst/icons/svg/wazuh.svg

`icon-dark.svg` is the upstream file with one change: the `fill` attribute `#fff` was added to the
main path so the letterform is white on dark backgrounds. The shape and the blue dot are unchanged.
